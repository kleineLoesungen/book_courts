<task type="auto">
  <name>Task 1: Create deploy.sh FTP deployment script</name>
  <files>deploy.sh</files>
  <action>
Create deploy.sh at the project root implementing the following exactly:

1. Shebang `#!/usr/bin/env bash` and `set -euo pipefail`.
2. Resolve SCRIPT_DIR as the absolute directory containing the script via `cd "$(dirname "${BASH_SOURCE[0]}")" && pwd`. This is the local source directory that gets mirrored to the server.
3. Parse arguments: accept an optional `--dry-run` flag, stored as `DRY_RUN="--dry-run"` when present (empty string otherwise). Reject any other unrecognized argument with a clear error message and non-zero exit.
4. If `"$SCRIPT_DIR/.env.deploy"` exists, source it with `set -a`, `source "$SCRIPT_DIR/.env.deploy"`, `set +a` so its variables are exported without leaking into positional-argument logic. Do not require this file to exist; it is optional, gitignored, and holds real credentials locally only.
5. Check `command -v lftp`. If missing, print to stderr: "Error: lftp is not installed. Install it with: brew install lftp" and exit 1. Do this check before validating env vars.
6. Default the port: `: "${DEPLOY_FTP_PORT:=21}"`.
7. Validate these env vars are all non-empty: DEPLOY_FTP_HOST, DEPLOY_FTP_USER, DEPLOY_FTP_PASS, DEPLOY_FTP_REMOTE_DIR. Collect missing names into an array; if any are missing, print to stderr "Error: missing required environment variables: <names>" plus a hint to set them in the shell or in a local .env.deploy file (see .env.deploy.example), then exit 1.
8. Print a one-line status message before deploying showing host, remote dir, and dry-run indicator. Never print DEPLOY_FTP_PASS.
9. Invoke lftp with credentials passed ONLY via stdin inside an unquoted heredoc, so shell variables interpolate into the text sent to lftp's stdin and never appear as `-u` command-line flags visible via `ps`. Use this exact structure:

```
lftp <<LFTP_EOF
set ftp:ssl-allow no
open -u "${DEPLOY_FTP_USER},${DEPLOY_FTP_PASS}" -p "${DEPLOY_FTP_PORT}" "${DEPLOY_FTP_HOST}"
mirror --reverse --verbose ${DRY_RUN} --exclude-glob .git/ --exclude-glob .planning/ --exclude-glob .env.deploy --exclude-glob deploy.sh --exclude-glob node_modules/ "${SCRIPT_DIR}/" "${DEPLOY_FTP_REMOTE_DIR}"
bye
LFTP_EOF
```

   The `open -u "user,pass"` form (single comma-joined argument) is lftp's documented syntax for passing both username and password to `-u`. `set ftp:ssl-allow no` makes explicit this is plain FTP, not FTPS/SFTP.
10. Do not exclude `.env`, `.htaccess`, or `conf.php` from the mirror; they must upload to the server (protected there by the existing .htaccess FilesMatch rule, not by exclusion from deploy).
11. Run `chmod +x deploy.sh` after creating the file.
  </action>

  </verify>
